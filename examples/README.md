# examples — real things built on workbooks

Each example is a complete, living project: an app (or site) plus the agents
that run inside it. They exist to be read — the point of a workbook is that
you can open it like a document.

| example | what it is | status |
|---|---|---|
| [living-lander](living-lander/) | workbooks.sh itself — a website that builds itself in public. One resident agent (Waldo) grows the page, writes the blog, and keeps a roadmap; every change is a public commit you can watch land live. | **live** at [workbooks.sh](https://workbooks.sh) |
| [bit-ml](bit-ml/) | bit.ml — an agent-run editorial service ("if Linear designed the New York Times"): bite-digestible AI/ML, tech, and finance news produced by a multi-agent pipeline you can watch work in real time. | **scaffold** — design + agent definitions, build starting |
| [brandnana](brandnana/) | a brand-intelligence service: agents that read a company's website and produce a complete brand book (palette, type, voice, imagery) as a workbook. | source not yet published (scrub pass pending) |
| [adbuy](adbuy/) | a video-game ad-buying experiment. | ⏸ unfinished — paused, source not published |
| [groundwork](groundwork/) | zero-to-one ideation as a workbooks method: raw founder material (voice memos, videos) transcribed verbatim, then audited into living org documents — every claim status-tracked against the shipped repo, the gap becomes the backlog. | **started** — first source (91-min spoken thesis) transcribed + claims ledger seeded |

The lander's agent knowledge (its def, skills, design laws) lives in
[living-lander/agent](living-lander/agent/); the tenant's live history mirrors
to [workbooks-sh/living-lander](https://github.com/workbooks-sh/living-lander).
