# Deployment config — single-tenant, all-local. The 90% case: run the runtime on
# your own machine in a krunvm microVM (cloud-identical isolation). File-based by
# design: edit, then  `work deploy validate <file>`  →  `work deploy apply <file>`.
# (Or just `work deploy local` for the zero-config equivalent.)

* local                                                      :deployment:
  :PROPERTIES:
  :ID:            local
  :ENGINE_PLACE:  local
  :TENANCY_MODE:  single
  :STORAGE:       local-fs
  :DATABASE:      sqlite
  :AUTH:          trusted
  :END:

** Notes
   local-fs + sqlite = the working data IS the store, no credentials, no network
   backend. Single-tenant + trusted auth = no tenant tokens, no org/user model.
   The whole runtime runs in one Linux container so OS + filesystem isolation
   matches cloud. Bring a PROFILE to point it at an agent set.
