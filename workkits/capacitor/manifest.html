Wrapper around Capacitor, invoked as ~npx cap~ (no global install needed). The Workbooks use case: take a built workbook (=dist/<slug>.html=) and wrap it as a native iOS app — run it in the Simulator, build + sign an =.ipa= in Xcode, upload it to TestFlight, and manage the App Store Connect side. This is a *host-side* workflow: it needs a Mac with full *Xcode.app* and runs the real Apple toolchain (=npx cap=, =xcodebuild=, Xcode Organizer / Transporter). It is NOT an in-sandbox capability — walk the user through it, or drive it on a Mac that has Xcode. NOTE — drift correction (wb-2qy2): earlier versions documented a =work forge mobile <cmd>= command surface backed by =cli/deploy-kit/mobile/= recipes. That lane was removed with the Rust =wb= (2026-06-09) and the recipes no longer exist. This toolkit is now grounded on the *real, present* tools: =npx cap= for the project + sync, and Xcode / standard Apple tooling for sign + upload. Do NOT invoke =work forge mobile= — it is not a command. Command surface (the real tools — ~npx cap --help~ is authoritative): - =npx cap add ios= — scaffold the native iOS project (once). - =npx cap copy= — copy the workbook HTML (staged in =www/=) in. - =npx cap sync= — copy + update native deps/plugins. - =npx cap open ios= — open the project in Xcode (archive, sign, run). - =npx cap run ios= — build + launch in the iOS Simulator / a device. Sign + distribute happen in *Xcode* (Product → Archive → Distribute App) or via =xcodebuild -exportArchive=; upload to TestFlight via the Xcode Organizer, the *Transporter* app, or =xcrun altool --upload-app= with your App Store Connect =.p8=. The ship-a-workbook-to-ios skill walks the whole path, including the one-time Apple Developer / App Store Connect setup. Signing + upload use the *user's own* Apple Developer account and an App Store Connect API key (a =.p8= under =~/.appstoreconnect/private_keys/=) — Workbooks never holds Apple credentials. Some setup is genuinely one-time and manual (Apple Developer Program enrollment, agreements, the App Store Connect app record); the ship-a-workbook-to-ios skill walks the user through all of it. Requires full *Xcode.app* (CommandLineTools cannot archive or sign), Node 18+; CocoaPods is optional on Capacitor 8+ (it uses Swift Package Manager).
