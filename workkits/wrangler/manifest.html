Wrapper around the standard =wrangler= binary. The Workbooks use case is one-shot: ship a built workbook (=dist/<slug>.html=) to Cloudflare Pages on the *user's own* Cloudflare account, via raw =wrangler pages deploy=. (There is no =work forge web= command — that wrapper was removed with the Rust =wb=, 2026-06-09; =toolkits/wrangler/deploy/cloudflare.sh= remains as an optional staging helper.) Auth is wrangler's own browser login (=wrangler login=) — the OAuth token lives in =~/.wrangler=, never in anything Workbooks stores or proxies. =wrangler --help= and =wrangler pages deploy --help= remain authoritative for per-flag detail. The skills cover the end-to-end deploy task.
