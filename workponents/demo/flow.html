work-flow · a runnable workflow in one file

No script, no runtime, no JSON. The whole workflow below is just authored HTML — an <ol> runs in sequence, the <ul> pair runs in parallel, each leaf's <work-src> executes through the Dock (sandboxed JS here), they thread a shared ctx, and a <work-ref rel="when"> loops back until the mean settles. The element runs itself — its light DOM is the flow (the work), its rendered checklist is the view (the book). Hit ▶ run.

  1. ctx.nums = [5,8,3,9,4,7,6,5,8,5]; return `seeded ${ctx.nums.length} numbers`;
  2. ctx.sorted = [...ctx.nums].sort((a,b)=>a-b); return ctx.sorted.join(", ");
    • await sleep(300); ctx.min = Math.min(...ctx.nums); return ctx.min;
    • await sleep(300); ctx.max = Math.max(...ctx.nums); return ctx.max;
  4. ctx.sum = ctx.nums.reduce((a,b)=>a+b,0); ctx.mean = +(ctx.sum/ctx.nums.length).toFixed(2); return `sum ${ctx.sum}, mean ${ctx.mean}`;
  5. ctx.pass = (ctx.pass||0)+1; ctx.needsRefine = ctx.mean > 4; if (ctx.needsRefine) ctx.nums = ctx.nums.map(n => n-1); // refine: pull the whole set down return ctx.needsRefine ? `pass ${ctx.pass}: mean ${ctx.mean} > 4 → refine & loop` : `pass ${ctx.pass}: mean ${ctx.mean} ✓ settled`;
