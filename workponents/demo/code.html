<wb-repl> — JavaScript, run in a sandbox

Press Run. The snippet executes in a Web Worker — no DOM, no page globals — and console.log + the returned value stream into the output pane.

const fib = n => n < 2 ? n : fib(n - 1) + fib(n - 2); const xs = Array.from({ length: 10 }, (_, i) => fib(i)); console.log("fib(0..9):", xs.join(", ")); // the returned value is shown too return { sum: xs.reduce((a, b) => a + b, 0), max: Math.max(...xs) };

<wb-editor> — highlight + line numbers

A themed editor: transparent textarea over a token-highlighted overlay, gutter line numbers, language attr. Edit it — it emits wb-code-change (watch the events line above). The editing surface is swap-stable: a CodeMirror engine backs it later behind this same API.

// edit me — keywords, strings, numbers, comments highlight fn main() { let greeting = "hello from workponents"; let answer = 42; for i in 0..3 { println!("{} #{}", greeting, i + answer); } }

<wb-repl> — compiled language, standalone

No runtime connected, so C can't run here — the REPL says so plainly instead of faking output. Connect a runtime (host.available("compile")) and the same code compiles + runs in-sandbox via the compiler lane.

#include <stdio.h> int main(void) { for (int i = 0; i < 3; i++) { printf("compiled in-sandbox: %d\n", i * i); } return 0; }
