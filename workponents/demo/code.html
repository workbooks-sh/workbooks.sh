<work-editor> — CodeMirror 6, themed from the token set

The editing surface is swap-stable behind one public API (value / language / work-code-change). By default it lazy-loads CodeMirror 6 from a CDN and themes it entirely from --work-* — flip the theme above and the editor re-themes with everything else. If CodeMirror can't load it falls back instantly to the zero-dep textarea+highlight floor. The tier in use shows on the right. Edit it — it emits work-code-change.

<work-repl> — compiled language, standalone

No runtime connected, so C can't run here — the REPL says so plainly instead of faking output. Connect a runtime (host.available("compile")) and the same code compiles + runs in-sandbox via the compiler lane.

#include <stdio.h> int main(void) { for (int i = 0; i < 3; i++) { printf("compiled in-sandbox: %d\n", i * i); } return 0; }
