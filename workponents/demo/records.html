workponents · records

A record is a row. The detail view of one entity is a query that returns one row; a record list is the index of entities over the same engine that backs tables, data-viz, and maps — never a second data store. Field values render typed off the result's types[] (currency, date, boolean, link, badge). Native custom elements, one token set, no build. Toggle the theme; everything re-themes.
