The spine is 3 elements — work-src (compute), work-ref (every edge, incl. type via rel=), work-flow (the DAG). Everything else is a toolkit: 52 built elements regrouped into 20 visual toolkits, each owning its own <prefix-*> (work-table → grid-table). "What something is" is an edge, not an element — there's no <work-toolkit>. Generated from the CEM — node tools/catalog.js.

EVERY EDGE. Dependency, link, binding — AND type. rel= turns it into a reified type-assertion (rel=toolkit|skill|agent), so 'what something is' lives in the same graph as deps. Meaning comes from where it sits + rel.
