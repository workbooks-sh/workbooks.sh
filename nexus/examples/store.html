Corner Store

A tiny living workbook — one file of prose, a database, and a compiled unit — that nexus

brings up end to end. Open the woven .html, or run it:

  • Nexus.Compile.workbook("examples/store") materialises the Product database and lists the

wasm units

  • Nexus.Weave.weave("examples/store") renders this whole folder to one self-contained page

Everything below is authored as .work; nothing here is hand-written HTML or JSON.

Pricing logic, compiled

A c unit is real C, compiled to a wasm component by our own toolchain (clang, run in-sandbox)

and executed on wasmex. discount takes a price and a percent and returns the marked-down price.

The now cap (a host capability the unit imports) stamps when the sheet was priced — a typed

WIT import the Dock supplies, granted explicitly in the header.

The catalogue

A resource is the database. Declare the shape and nexus derives a live Ash resource —

real CRUD, the inline status enum becomes a real constraint. No schema files, no migrations.
