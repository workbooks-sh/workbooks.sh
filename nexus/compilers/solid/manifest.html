The Solid transform is a multi-MB babel bundle — too heavy for QuickJS (~80s) so it runs on StarlingMonkey (Nexus.JsEngine, SpiderMonkey→wasm) in ~1.2s. vendor/babel.js exposes globalThis.solidTransform(code, filename) → compiled Solid JS (dom-expressions: _$template / createComponent). Built by build.sh (esbuild, node:assert aliased to a real shim). Driver: Nexus.Compilers.Js.transpile(:solid, _). A `solid` unit is a CLIENT island (compiled JS imports solid-js/web + needs a DOM), emitted as {:client, js} by Nexus.Compile. STATUS: WORKING.
