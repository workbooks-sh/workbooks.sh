- =stem-build.ogg=: ambient low-energy loop (BUILD state, no flight yet)

* Implementation notes

** Silent switch (iOS)

Web Audio in WKWebView plays through the iOS silent switch (unlike HTML5
=<audio>=). No native AVAudioSession routing needed. Confirmed behavior on
iOS 15.4+; no special handling required.

** AudioContext unlock

=unlockAudio()= in audio.js must be called in the first user gesture handler.
Currently wired to the dashboard's first interaction. Verify it fires before any
SFX attempt — early calls to SFX functions check =live()= and no-op silently if
context not running.

** OGG vs WAV

Vite bundles audio files via =?url= import. For mobile: OGG Vorbis is ~30%
smaller than WAV; Capacitor/WKWebView supports OGG on iOS 11+. Use OGG for
stems, WAV for short SFX (WAV decodes faster).
