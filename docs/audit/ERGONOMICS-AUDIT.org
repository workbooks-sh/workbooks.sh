Grounded against the code (workflow wf_1eeaf15a-40d, 5 agents) from a real

* HEADLINE — the single biggest loop drag
  Profile/boards/toolkits are baked into the read-only image, so a ONE-LINE .org
  prompt/skill/board edit forces a full ~8-15min Rust+bun+Elixir rebuild + restart
  — even though the engine reads them LIVE per-request (agent_def.ex:153 File.read,
  no boot cache). Fix (deploykit·M): (1) seed COPY → /opt/profile.default, boot
  rsync-if-empty into /data/profile, set WB_PROFILE_DIR=/data/profile; (2) add
  `wb profile sync` → new POST /api/profile/files (clone WorkspaceController.write_
  files base64+root-confine primitive). Prompt-tweak loop: ~10min → seconds.

* Deploy cycle
  - [deploykit·M·high] Cargo builds (workbooks-embed ~75 crates + wb-cli) have NO
    --mount=type=cache (mix/bun stages do) → full recompile every deploy. Fix: add
    registry/git + target cache mounts; CAUTION cp the binary OUT of the cache-
    mounted target (the wb-lb3o.17 / 1f4d4c2e0 lesson — cache mounts aren't in the
    layer FS for the final COPY --from).
  - [deploykit·S·high] fly.bn-engine.toml has NO [checks] block → --strategy
    immediate mandatory → mid-run kill. /api/health EXISTS (router.ex:38). Fix: add
    [[http_service.checks]] → /api/health, drop hardcoded immediate (propagate.sh:52).
  - [engine·L·med] Mid-run deploy kills the in-flight board (in-memory GenServer;
    Board.Supervisor is an EMPTY DynamicSupervisor, no boot recovery) → stale
    :in_progress + un-released claim. = wb-defh part-2 (boot recovery scan + drain).

  - [engine·S·high] wb-defh silent-discard root FIXED (042a0f18b, has_id? padded

* Query engine + book-as-backend

    bare clap error. Fix: optional positional path + "did you mean --path?" hint.
  - [workbook-cli·M·high] `wb workbooks query` → /api/workbook/query 404 + --count
    usage error: production-lag (redeploy) + needs --engine/--token + no local fallback.
  - [brandnana·M·high] The deck publish path trusts agent HTML VERBATIM and never
    (re)builds the wb-source-bundle (the wb-ann4 root). `wb embed-source` mitigates
    agent-side; ROBUST fix: publish.ts validate-or-rebuild the bundle SERVER-SIDE so
    a hand-rolled/missing bundle can't ship.
  - [deploykit·S·low] forge toolchain now ships next to wb in BOTH spots (fixed).
