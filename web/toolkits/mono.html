mono

Experimental Design v0.1.0

RGBA → grayscale, the first deployed kernel-shape toolkit (bytes→bytes hot loop).

What it does

The DEBUT of the #+EXEC: kernel shape: a bytes → bytes reactor compiled from C (in-sandbox, clang.wasm) and looped by the fabric — instantiate ONCE, call per frame. Input: RGBA pixels; output: same-length RGBA with each pixel

Capabilities it grants

fontssandbox

Add it to a workbook

$ wbx toolkit add mono

Once added, the toolkit is wired into the workbook's Dock — the agent reaches its verbs by name, the host brokers any capability it needs. Read the docs →

Integration

This is a self-contained capability — no external account or key required. It runs inside the workbook's sandbox and is reachable through the Dock the moment it's added.
