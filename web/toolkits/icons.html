icons

Experimental Assets v0.1.0

The universal icon library as a CLI — one value grammar (mi:<def> · lobe:<slug> · emoji · data: · initials) searched, resolved, and explained; what an agent writes renders in the desktop unchanged.

What it does

One CLI fronts the project-wide *icon value grammar* (wb-5fl.15/.16): the same strings the desktop resolves in desktop/src/lib/ui/Icon.svelte — Material Icon Theme defs for files/folders/anything, LobeHub brand svgs for

Capabilities it grants

web-searchfetchassetsgitdesktopsandboxaitasks

Add it to a workbook

$ wbx toolkit add icons

Once added, the toolkit is wired into the workbook's Dock — the agent reaches its verbs by name, the host brokers any capability it needs. Read the docs →

Integration

This is a self-contained capability — no external account or key required. It runs inside the workbook's sandbox and is reachable through the Dock the moment it's added.

The flow

`icons grammar` once → `icons search <query>` / `icons for-file <name>` / `icons for-folder <name>` to find a value → write that string into the workbook/spec. `icons get <value>` to inspect any value you meet. cat skills/overview.org only if a verb surprises you.
