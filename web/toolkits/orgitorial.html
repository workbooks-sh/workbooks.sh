orgitorial

Experimental Pipeline v0.2.0

An org-mode blogging/CMS toolkit you plug into any site — a zero-dependency org→HTML renderer (browser / Node / QuickJS-wasm), a complete editorial CSS library themed by custom properties, and skills documenting the stable class contract. Plain HTML semantics, no framework.

What it does

A *knowledge + assets* toolkit: a small org-mode CMS you can drop into any website. Three parts ship together —

Add it to a workbook

$ wbx toolkit add orgitorial

Once added, the toolkit is wired into the workbook's Dock — the agent reaches its verbs by name, the host brokers any capability it needs. Read the docs →

Integration

This is a self-contained capability — no external account or key required. It runs inside the workbook's sandbox and is reachable through the Dock the moment it's added.

The flow

read this front door → pick the one skill your task needs (integrate to plug it in, authoring to write content, components for the class catalog, theming to re-skin). cat a skill only when you reach its step. The renderer + css live in dist/; a working proof page is dist/specimen.html.
