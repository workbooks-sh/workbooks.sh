palette

Experimental Design v0.1.0

The WASM build/runtime palette — language runtimes & compilers as pinned, sandboxed commands (one set, not separate packages).

What it does

ONE toolkit holding the whole set of WASM build/runtime tooling — NOT separate packages. Each entry in runtimes/ is a pinned prebuilt (or build recipe) for a language: fetch + sha-verify + (unpack) + register as a sandboxed command. Run

Add it to a workbook

$ wbx toolkit add palette

Once added, the toolkit is wired into the workbook's Dock — the agent reaches its verbs by name, the host brokers any capability it needs. Read the docs →

Integration

This is a self-contained capability — no external account or key required. It runs inside the workbook's sandbox and is reachable through the Dock the moment it's added.
