publish

Stable Deploy v0.1.0

AT Protocol publishing + Workbooks Network identity — bind a Bluesky account, publish signed workbooks, watch the verified feed.

What it does

The publish/identity stack, lifted out of the `wb` core (M5-publish-to-toolkit — provider/integration logic lives in toolkits). The toolkit OWNS the `wb-publish` binary: its source

Capabilities it grants

authtasks

Add it to a workbook

$ wbx toolkit add publish

Once added, the toolkit is wired into the workbook's Dock — the agent reaches its verbs by name, the host brokers any capability it needs. Read the docs →

Integration

This is a self-contained capability — no external account or key required. It runs inside the workbook's sandbox and is reachable through the Dock the moment it's added.

Requires: wb-publish>=0.1.0
