#+TITLE: the context repository
#+CATEGORY: agents
#+DEK: An agent's context is not a transcript. It is a queryable repository written in org: remember with tags, recall by relevance, compact without losing the plot.

* a transcript is not a memory

The naive agent memory is keep-the-conversation. It dies two ways: it grows
until it does not fit, and the one fact you need is buried in noise. A
context repository stores small, tagged notes instead, and in this
ecosystem the repository is org. Here is an agent's memory after a week of
work. Flip to the source tab to see the org; the tags on each headline are
real org tags.

#+begin_src org :name memory :view doc
* user prefers light hero art, no nighttime scenes   :style:art:
* deploy target is fly, app name wb-site             :deploy:
* the keeper crashed twice on June third             :ops:incident:
* palette is live green on paper                     :style:brand:
#+end_src

* recall is a query, not a scroll

When the agent needs context, it asks for what is relevant. The kernel
parses the memory canonically, so tags are structure, not punctuation.

#+begin_src js :action recall everything tagged style
nb.notes = () => nb.oql.headlines(nb.org("memory"));
nb.recall = (tag) => nb.notes().filter((n) => n.tags.includes(tag));
for (const n of nb.recall("style")) print(`[${n.tags.join(", ")}] ${n.title}`);
print("only what matters enters the model's context - never the whole repository");
#+end_src

* compaction without amnesia

Repositories grow. The fix is not deletion: it is summarizing old notes
into fewer, denser ones. Watch the document above gain a summary line.

#+begin_src js :action compact the style notes
const old = nb.recall("style");
if (old.length < 2) { print("nothing to compact"); return; }
const summary = "* SUMMARY: " + old.map((n) => n.title).join("; ") + "   :style:summary:";
nb.org("memory", nb.org("memory").trim() + "\n" + summary);
print("compacted " + old.length + " notes into one summary - it is in the document now");
#+end_src

In the live ecosystem this is the workbook's org layer: notes are headlines
with real timestamps, recall is a tree query, and compaction is a chore the
[[autopoet.html][gardener]] runs. The [[agents.html][agents lesson]] calls
this the difference between a goldfish and a colleague.

#+begin_recipe
Implement a context repository for my agent, written in org.

Build: a memory file of org headlines, one note per headline, with org
tags carrying the categories. Three operations: remember(text, tags)
appends a headline; recall(tag or query) returns matching notes parsed
canonically, ranked by tag match then recency; compact(tag) replaces
nothing but appends one summary headline naming what it condensed.

Requirements:
- The agent writes notes at decision points, not a transcript.
- recall() output is what enters the model context, never the whole file.
- Compaction keeps the original notes for provenance and is triggered by
  size, as a maintenance chore.

Acceptance: after fifty notes and one compaction, recalling any earlier
decision surfaces either the original note or a summary that names it.
#+end_recipe
