what is a workbook ■ 01

the ATOM of a living internet.

  • It's the glue. One agnostic format for any data, any system, any language — people, services, and code all meet in the same file.
  • It becomes anything. The same workbook ships as a mobile app, a desktop app, or a website — no porting, no rebuilds.
  • It carries its own infrastructure. Every workbook runs a sandbox for its code, a database for its state, and agents that keep it building.
