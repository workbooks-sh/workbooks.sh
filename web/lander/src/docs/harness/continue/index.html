Harness · Continue

Continue.

Continue is an open-source coding assistant that runs as a VS Code or JetBrains extension. MCP support is in its YAML config.

Auto-install

Paste this into Continue

Click below to copy a self-install prompt. Paste it into a Continue Agent-mode session and it'll edit the YAML config and reload itself.

Or follow the manual steps below.

1. Install the CLI

npm install -g @work.books/cli

2. Open Continue's config

In VS Code: ⌘+⇧+P → Continue: Open Config. This opens ~/.continue/config.yaml.

3. Add the Workbooks server

mcpServers:
  - name: workbooks
    command: workbook
    args:
      - mcp
      - serve

Save. Continue reloads MCP servers on save.

Quirks & tips

  • YAML, not JSON. Newer Continue versions moved from config.json to config.yaml. If you have an older install, the equivalent JSON lives at experimental.modelContextProtocolServers.
  • Agent mode only. MCP tools only fire in Continue's Agent mode. Chat mode ignores them.
  • JetBrains parity. The JetBrains extension reads the same ~/.continue/config.yaml, so the setup carries across IDEs.

Verify

Switch Continue into Agent mode and ask: "List my Workbooks groups."
