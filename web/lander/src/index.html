WHAT IT IS

A self-contained runtime, not a framework you assemble. One Elixir engine supervises everything; your logic compiles to WASM and executes on the BEAM alongside it — concurrency, fault isolation, and process supervision from the platform, not from glue you maintain.

THE WORKBOOK IS THE UNIT

A workbook is a single file that carries its own data, its own code, and a query interface over both. It is the source you edit, the artifact you ship, and the thing you query in place. Hand someone the file and they have the running app, not a link to one.

BUILT TO SELF-HOST

Everything runs on infrastructure you control. One OTP application with no hidden dependency on a hosted backend. Nothing to phone home, nothing to lock you in. Open source under a permissive license — audit the trust boundaries yourself.
