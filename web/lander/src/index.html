A document that runs.
A toolkit that makes it do more.

A workbook is one .org file — prose, code, and data — that compiles to WebAssembly and publishes as a single .html. A toolkit is how you extend it: sandboxed WASM, any language, run isolated, shipped inside the workbook.

# a toolkit is a workbook — ship it by hash
$ wb pack rev rev.wbundle

two surfaces

Workbooks are what you ship. Toolkits are how you make them do more.

Everything you build is one of two things — and they compose. A toolkit travels inside a workbook; a workbook calls a toolkit live.

the artifact

Workbook

One .org file that renders and runs. Source blocks compile to WASM; the result publishes as a self-contained .html you can open anywhere. The document is the app.

the capability

Toolkit

Sandboxed WASM that does one thing — written in any language, compiled in the sandbox, run isolated, distributed as a workbook. The unit of capability, called by agents, workbooks, and workflows alike.

one package, six contracts

A toolkit picks a shape

One #+EXEC line selects how the artifact is invoked. Same package format, same build pipeline, same trust model.

command

argv + stdin → stdout. A CLI compiled to WASM — the default, the 80% case.

component

A WIT-typed component called in-process, with a real typed API surface.

kernel

A bytes → bytes hot loop. Instantiated once, run millions of times — the render shape.

task

A runnable recipe, no compiled binary. The value is the procedure.

federation

A live data source: SELECT … FROM routes to any JSON API, with an optional sync daemon.

posix

The native escape hatch, for what WASM can't do — contained, deployer opt-in.

one substrate, not three

The document, the runtime, and the package system — collapsed into one.

  • 1The document is the app.A workbook renders and runs — no build pipeline, no config, one file in and one URL out.
  • 2The toolkit is the capability.Sandboxed WASM, capability-gated, isolation-tiered — written in the language you already use.
  • 3Distribution is the document.A toolkit ships as a workbook; install verifies it by hash. No separate registry to run.

safe by construction

A toolkit can't reach your machine.

WASM has no ambient authority — no syscalls, no sockets, no filesystem. It does only what the Dock grants, and the host decides how isolated it runs across four escalating tiers.

  • ↑Escalation is one-way.The host can only tighten. More untrusted means more contained — assigned, never requested.
  • ⛨The host holds the keys.A toolkit that fetches a URL never sees the API key and never opens a socket.
