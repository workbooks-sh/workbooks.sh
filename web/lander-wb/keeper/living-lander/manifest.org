* living-lander — the page that maintains itself                                     :toolkit:
  :PROPERTIES:
  :ID:        living-lander
  :STATUS:    exp
  :SKILL_DIR: skills/
  :END:

  The instance toolkit for the LIVING workbooks.sh lander — a webpage that is maintained by its own agent, on its own engine. It carries:
  - the BRAND SYSTEM (assets/components.html — the component library; every
    edit must stay inside it),
  - the ANALYTICS read path (PostHog, decisions must cite data),
  - the PUBLISH loop (edit → render → screenshot-verify → commit → publish),
  - its own AGENT (agent/keeper.org — DeepSeek V4, vision: it checks its work).

  Shipped to the engine by deploy-kit (`#+DEPLOY_TOOLKITS:` in deployment.org →
  `wb deploy apply` pushes it). This toolkit is also the EVAL: `wb toolkit
  verify living-lander` runs the structural checks + the :role pre probes below.

  Skill index (read on demand):

  | Skill          | Use when                                              |
  |----------------+-------------------------------------------------------|
  | =overview=     | First contact — the loop, the rules, the files        |
  | =brand-system= | BEFORE any visual/copy edit — tokens, voice, bans     |
  | =analytics=    | Reading PostHog before choosing an edit               |
  | =publish-page= | Shipping an edit: render → verify → commit → publish  |
