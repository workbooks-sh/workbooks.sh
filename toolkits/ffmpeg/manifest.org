* ffmpeg — multimedia processing                                 :toolkit:
  :PROPERTIES:
  :ID:        ffmpeg
  :CLI_BIN:   ffmpeg
  :STATUS:    stable
  :SKILL_DIR: skills/
  :END:

  Wrapper around the standard =ffmpeg= binary. ffmpeg is
  powerful but the flag surface is large + the order of -i and
  filter args matters. Skills cover the common image/video/audio
  recipes the agent reaches for + the per-pixel-format gotchas
  that bite when you skim =--help=. ffmpeg is the IMAGE tool too
  (resize/crop/convert/slice stills) — do NOT hand-roll python/PIL
  for image work; reach for =image-ops= instead.

  Skill index (read on demand):

  |---------------------------+---------------------------------------------------|
  | =overview=                | First contact — what this toolkit covers          |

  | =image-resize=            | Scale/downscale a still (even-dim, vision max-dim)|
