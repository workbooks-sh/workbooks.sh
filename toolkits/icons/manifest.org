  One CLI fronts the project-wide *icon value grammar* (wb-5fl.15/.16): the
  same strings the desktop resolves in =desktop/src/lib/ui/Icon.svelte= —
  Material Icon Theme defs for files/folders/anything, LobeHub brand svgs for
  AI/dev logos, emoji, =data:= images, initials. An agent never invents an
  icon URL; it asks =icons= for a *value* and writes that string. *Grammar
  sync is the contract*: this toolkit and =Icon.svelte= carry the same
  grammar with cross-referencing notes — change one, change the other.

  Verbs (all take =--json=; line mode is =value<TAB>kind<TAB>name<TAB>url=):

  | verb                              | what it answers                                        |
  |-----------------------------------+--------------------------------------------------------|
  | =icons search <query>=            | "an icon for X?" — unified over material defs + emoji names + lobe slugs, ranked exact > prefix > substring (=--kind=, =--limit=) |
  | =icons for-file <filename>=       | the material def for a file — fileNames > longest multi-dot extension > default |
  | =icons for-folder <name> [--open]= | the material def for a folder (expanded variant with =--open=) |
  | =icons get <value>=               | resolve ANY grammar value → kind / source / URL / fallback behavior |
  | =icons grammar=                   | print the value grammar (the sync contract, agent-readable) |

  Data is *vendored, committed, regenerable* (the glyphs convention):
  =packs/material.json= (manifest mappings + the def list, pinned to the
  desktop's material-icon-theme version), =packs/lobe.json= (the brand-slug
  list), =packs/emoji.json= (gemoji name → char) — regenerated by
  =scripts/build-packs.mjs=, which also bakes the packs into the committed
  =src/index.js= (the QuickJS wasm lane compiles ONE file: logic lives in
  =src/cli.js=, never edit =src/index.js=). SVG bytes are NOT bundled —
  =get=/=search= emit stable CDN/raw URLs (jsDelivr for material, the
  lobe-icons raw.githubusercontent pattern for brands).

  Build/run: =work toolkit build icons= compiles =src/index.js= in-sandbox
  (QuickJS lane) and registers the =icons= command; agents call it from bash.
  =#+ARG_MODE: stdin1= — the registry folds argv into the first stdin line
  (the JS harness sees no real argv). Outside the runtime the same file runs
  under plain =node src/index.js=.
