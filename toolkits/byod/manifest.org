* byod — workbook → app with a live backend + auth                :toolkit:
  :PROPERTIES:
  :ID:        byod
  :VERSION:        0.1.0
  :CLI_BIN:   wb
  :STATUS:    experimental
  :SKILL_DIR: skills/
  :END:

  Connect a forged workbook to a live database (Postgres, or Cloudflare D1)
  through a secure data backend, with the developer's OWN auth (BetterAuth) for
  sign-in, sessions, organizations (multi-tenant), and API keys. No agent engine
  required.

  STATUS: the turnkey provisioning (=work forge app deploy=) + its unified gateway
  (=deploy-kit/app/gateway=) were removed 2026-06-09 and are NOT currently
  available (restore-or-drop tracked in =wb-dtd0.1=). Do NOT invoke =work forge
  app=. The skill still gives the (real, current) architecture + frontend wiring,
  and points at the live provider tools to stand up the backend yourself
  (=cloudflare= / =railway= / =wrangler= toolkits + BetterAuth).

  The workbook .html is the frontend; the backend + auth deploy SEPARATELY and
  are pointed at via a PUBLIC connection descriptor injected into the .html —
  never DB credentials or server code.

  Skill index (read on demand):

  | Skill                              | Use when                            |
  |------------------------------------+-------------------------------------|
  | =connect-a-workbook-to-a-database= | Give a forged workbook a live Postgres + the developer's own auth (sessions, orgs, API keys), no engine |
