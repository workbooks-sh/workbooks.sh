Real upstream CLIs/runtimes compiled to =wasm32-wasi= and run under wasmtime in the sandbox via the =run-command= Dock import (host: =Workbooks.CommandRegistry.run/3-5=). ZERO native execution — each command IS a sandboxed wasm module, stdin → stdout, argv passed through. FIVE lanes in =Workbooks.Pallet= provide them: prebuilt-WASI artifacts (=@catalog=), C/C++-from-source (=@csource=, built in-sandbox via =clang.wasm= — handles amalgams via =:include_only=/=:compile_only=, config substitution, and multi-tarball =:deps=), Rust crates (=@rust= via =mrustc=→clang), pure-Python (=@python_tools= on CPython.wasm), and npm/JS (=@js_tools= — an npm package bundled in-sandbox via esbuild and run on Javy/QuickJS). All are seeded at boot, then persisted + reloaded (no rebuild). Unlike git/ffmpeg/etc., this toolkit is not ONE wrapped CLI — it is the INDEX of the command set the agent can reach.
