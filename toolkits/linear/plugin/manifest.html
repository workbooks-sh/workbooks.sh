The OQL read face (face 2 of 3) of the =linear= federation toolkit. Registering this plugin routes =SELECT ... FROM linear-issue= queries to =WorkbooksRuntime.Plugin.Linear.query/3=, which translates the OQL AST to Linear's GraphQL API and returns headline-shaped maps. This face is READ-ONLY and pull-on-demand — no resident process. The persistent mirror (interval pull into =:task:= nodes) is the SEPARATE sync-daemon face (=../sync.md=), driven by =WorkbooksRuntime.Plugin.TaskSync=. Credentials (=LINEAR_API_KEY=) are fetched through =WorkbooksRuntime.Plugin.Auth=, never =System.get_env= directly. NOTE: =#+IMPL:= names the planned OQL query module (=WorkbooksRuntime.Plugin.Linear=); shipping it is wb-gi9i.3. This manifest is the authorable shape + a fixture for the DeployKit federation lint (wb-gi9i.8) to validate the three faces as a set.
