* wavelet — HTML-composition video renderer                       :toolkit:
  :PROPERTIES:
  :ID:        wavelet
  :VERSION:   0.2.0
  :CLI_BIN:   wavelet
  :STATUS:    experimental
  :SKILL_DIR: skills/
  :END:

  Wavelet renders *plain HTML + CSS* (or a timeline of HTML snapshots)
  to video and adjacent artifacts with NO external tooling — no Node,
  no native CLI, no GPU, no host browser. The pipeline is WHOLLY
  in-nexus:

  1. RENDER (in-sandbox). The carved render core (Blitz HTML/CSS +
     Stylo CSS-animation timeline + a CPU Vello rasterizer), compiled
     to wasm, paints the composition to a deterministic PNG frame
     sequence. Runs in the SAME sandbox as every other command.
  2. ENCODE (in-guest). =wb_encode.wasm= (our clang.wasm-built libx264
     + native AAC) muxes the frame sequence into an h264/yuv420p mp4
     INSIDE the sandbox — no host ffmpeg, no native exec, no broker
     grant for the default in-guest engine.

  The verb surface:

  | Verb       | Input → output                                              |
  |------------+-------------------------------------------------------------|
  | =render=   | one animated HTML composition → mp4                          |
  | =film=     | a TIMELINE of edit-state HTML snapshots → captioned mp4      |
  | =present=  | one HTML composition → pptx deck                            |
  | =audio=    | audio file → clean AAC =.m4a= (no video, fully in-guest)     |
  | image/gif  | render-core capabilities (=render_one= still / media GIF lane) |

  #+begin_src bash
  wavelet render clip.html -o out.mp4 --w 1280 --h 720 --fps 30 --duration 4
  wavelet film  timeline.json -o demo.mp4 --crossfade 0.4 --audio narration.mp3
  wavelet present deck.html  -o slides.pptx
  wavelet audio  voice.mp3   -o voice.m4a --bitrate 128
  #+end_src

  =render=/=film= take =--audio= (mp3/aac/wav muxed as AAC; NOT m4a —
  the ISO-BMFF container isn't decodable in-guest). =film= is how an
  in-nexus agent films its OWN workbook edits — each timeline entry is a
  state the agent authored; see =tools/record/IN-NEXUS-FILMING.md=.

  This REPLACES the old external =@work.books/wavelet-cli= assumption.
  No =init=, =preview=, =inspect= or trim verb — author the HTML (or the
  snapshot timeline), render the artifact, done.
