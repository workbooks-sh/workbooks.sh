#+TITLE: wavelet — preview + render
#+TOOLKIT: wavelet
#+SKILL: preview-and-render
#+TAGS: video preview render mp4 iterate
#+STATUS: stable

* When to use this
  :PROPERTIES:
  :NETWORK: yes
  :DESTRUCTIVE: no
  :END:

  You have a wavelet composition (typically scaffolded from
  [[file:scaffold-a-composition.org][scaffold-a-composition]]) and want to iterate visually then
  produce a final mp4.

* The dev loop

  =wavelet preview= opens a browser-based player at
  =localhost:5173= with hot-reload on source edits. Good for
  visual iteration before committing to a render.

  #+CAPTION: verify cwd looks like a wavelet composition
  #+begin_src bash :role pre
  test -f main.xml || { echo "no main.xml in cwd — is this a wavelet composition?"; exit 1; }
  #+end_src

  #+CAPTION: dev preview (open localhost:5173)
  #+begin_src bash
  wavelet preview
  # Ctrl-C to stop
  #+end_src

* Render to mp4

  =wavelet render= produces the final video.

  #+CAPTION: render at the composition's declared duration + dims
  #+begin_src bash
  wavelet render -o out.mp4
  #+end_src

  #+CAPTION: render at a specific size (e.g. 1080p portrait)
  #+begin_src bash
  wavelet render -o out.mp4 --width 1080 --height 1920
  #+end_src

  #+CAPTION: confirm output is a real mp4 with non-zero duration
  #+begin_src bash :role post :path out.mp4
  test -f "$1" || { echo "render missing"; exit 1; }
  ffprobe -v error -show_entries format=duration -of csv=p=0 "$1" \
    | awk '$1 + 0 > 0 { print "✓", $1, "seconds"; exit } END { print "✗ zero duration"; exit 1 }'
  #+end_src

* Gotchas

  - First render is slow (downloads fonts; warms caches). Subsequent
    renders re-use them.
  - =wavelet render= without =-o= writes to a default path the
    config declares — check =wavelet --help= for the current default.
  - If the renderer hangs on font fetch, check network reachability
    to fonts.googleapis.com / fonts.bunny.net / use.fontshare.com.
