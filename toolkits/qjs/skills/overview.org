#+TITLE: qjs — overview
#+TOOLKIT: qjs
#+SKILL: overview
#+TAGS: javascript js quickjs runtime sandbox prebuilt
#+STATUS: experimental

* When to use this
  :PROPERTIES:
  :NETWORK: no
  :DESTRUCTIVE: no
  :END:

  Reach for =qjs= to execute untrusted JavaScript without an OS process: the
  QuickJS engine is a pinned prebuilt WASM module run in the capability-gated
  sandbox. The build step is "fetch + verify a hash", not "compile" — so there is
  no native build code to trust.

* Install (one-time, from the committed pinned spec)

  #+CAPTION: fetch + sha-verify + register the qjs command from this manifest
  #+begin_src bash
  wb toolkit build qjs
  #+end_src

  The manifest pins the upstream URL and =#+SHA256=; the fetched bytes are refused
  if the hash does not match (supply-chain gate). The artifact is content-addressed
  into the command store and registered as the =qjs= command (arg mode: argv).

* Run JavaScript in the sandbox

  #+CAPTION: run a script — argv is the path, granted via a preopen dir only
  #+begin_src bash
  qjs /w/app.js
  #+end_src

  The script sees only what the preopen grants; no host network, no host FS.
