* qjs — JavaScript runtime (prebuilt WASM)                       :toolkit:

  The first "toolchain pallet": a language RUNTIME shipped as a pinned, prebuilt
  WASM module (quickjs-ng's =qjs-wasi.wasm=), not source we compile. `wb toolkit
  build qjs` fetches the pinned URL, verifies =#+SHA256=, content-addresses it into
  the command store, and registers it as the =qjs= command. Untrusted JS source is
  then run THROUGH it inside the sandbox — no native build step, no host access
  beyond the granted preopen. The runtime itself is trusted (pinned + hash-verified);
  the untrusted part is the user's script.
