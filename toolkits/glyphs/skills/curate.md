# glyphs — curate

# When to use this

Read this when your task is to *add a mark to the curated set* (so it's instant
+ offline) or *refresh* the curated JSON from the live sources. The curated set
is committed JSON with the SVGs inlined; the long tail resolves via the CDN at
runtime and needs no curation.

# What's curated, and why

Three committed files under `packs/`:

- `curated-brands.json` — `name → full-color brand SVG` (inlined). The marks
  bit.ml + the lander use, so they render instantly with no network.
- `curated-icons.json` — `name → currentColor tech-icon SVG` (inlined).
- `svgl-index.json` — svgl's `name(lowercase) → route URL` map. *No art* — just
  URLs, so a long-tail `brand:` is ONE runtime fetch of the svg (not an index
  round-trip). This is bundled, not the per-svg art.

Plus `packs/open-avatars/` — this repo's open-avatars renderer + the open-peeps
bundle, vendored so `avatar:` works with no network (refresh by re-copying from
`toolkits/open-avatars/`; see "Refreshing open-avatars" below).

Curate a mark only when it is *common enough to want offline / instant*. Anything
else just resolves through `glyphAsync()` at runtime — no curation needed.

# Add a curated mark

The source of truth is `scripts/build-curated.mjs` — it lists the curated brands
+ icons and fetches/inlines them. To add one, edit the list, then rebuild.

- A *brand*: add to `BRANDS`. Each entry is `{ name, svgl, si }` —
  - `name` : the `brand:<name>` id (lowercase).
  - `svgl` : the svgl `title` to match in the index (full color, preferred).
  - `si`   : a simple-icons slug fallback (lowercase, no spaces/dots), or `null`.
- A *tech icon*: add to `ICONS` as `'[name, simple-icons-slug]'`. simple-icons
  slugs strip spaces + dots (`nodejs → nodedotjs`, `vue → vuedotjs`).

Then:

```bash
node scripts/build-curated.mjs   # re-fetches + rewrites the three JSON packs
node test/glyph.test.mjs         # confirm the new mark is a sync curated hit
node test/build-specimen.mjs     # (optional) refresh the proof page
```

The script picks the *light* route when svgl offers `{light,dark}`, normalizes
the SVG (strips XML prolog/comments, collapses whitespace), and inlines it.
A brand with no svgl row and no simple-icons slug is skipped with a `✗` line —
that mark then resolves only via the CDN long tail (or not at all). That is the
honest outcome; do not hand-author a fake.

# Refresh the whole curated set

Re-run `node scripts/build-curated.mjs` any time. It re-fetches every curated
entry from the live sources and rewrites the JSON. Commit the updated JSON. Use
this when a brand changes its logo upstream, or to pull svgl's latest index.

# Refreshing open-avatars (the avatar: delegate)

`avatar:` delegates to this repo's `open-avatars` toolkit, vendored under
`packs/open-avatars/`. To refresh:

```bash
cp -f ../open-avatars/dist/open-avatars.js          packs/open-avatars/open-avatars.js
cp -f ../open-avatars/packs/open-peeps/pack.bundle.json packs/open-avatars/open-peeps.bundle.json
```

To offer more avatar packs, copy additional `pack.bundle.json` files in and
register them in the host's `configure({ avatarPacks: { … } })` (see
`skills/integrate`). open-avatars' own determinism contract is unchanged.

# Trademark — curate responsibly

Curated marks are *trademarks of their owners*, inlined for nominative /
identification use only. Do not edit a logo's geometry/colors in a way that
misrepresents the brand. See `LICENSES.md`.

# Done-when

The new mark is a *sync curated hit* (`glyph("brand:foo")` returns an SVG, not
`null`), the JSON is regenerated by the script (not hand-edited), and the test +
specimen still pass. If a brand isn't in any source, leave it to the long tail —
don't fabricate the art.
