=3w= (WWW) gives an agent the open web with no API keys and no per-call cost. It is NOT a generic browser wrapper: =search= is native multi-engine (ddg+bing+brave+mojeek merged by cross-engine consensus), =read= is a Chrome-impersonating fetch that falls back to a real JS render only when a page needs it. The defining goal — turning a research run into a portable *workbook context repository* — lands as the crawl/harvest/repo verbs come online (tracked in bd wb-ebwt). What an agent gets wrong from priors: reaching for =curl= (bot-walled, no JS) or assuming it must know a domain before reading it. =3w search= is the on-ramp — search first, then read the URLs it returns. Google is *intentionally absent* from the native pool (its wall is JS/behavioral and unrecoverable cheaply); don't try to force it — widen engines instead. Skill index (read on demand): | Skill | Use when | |----------------+------------------------------------------------------------| | =overview= | First contact — the verbs, the cost model, what's live yet | | =search= | Find pages on the open web by query (no key, no Google) | | =read-extract= | Pull a URL's content as clean markdown (JS-aware) | | =troubleshoot= | A search/read came back empty, walled, or CAPTCHA'd |
