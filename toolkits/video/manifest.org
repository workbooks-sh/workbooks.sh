* video — motion + clips                                  :toolkit:capability:video:
  :PROPERTIES:
  :ID:         video

  :SKILL_DIR:  skills/

  When the user asks for a *video*, *motion graphic*, *animation*, or *ad clip*,
  reach for this — do NOT hand-roll ffmpeg drawtext keyframes or a CSS-animation
  screen-record. A video is a *HyperFrames scene*: a typed, deterministic
  animation authored against a fixed canvas, which wavelet renders to a clip.

  The brand is incidental. The agent calls the *capability* ("make a video");
  this toolkit resolves it to the HyperFrames impl
  (=@work.books/wavelet-hyperframes=). Swap the impl here without touching any
  agent that asks for "video".

  The shape: a scene module imports =onReady=, =onTick=, the canvas constants
  (=CANVAS_WIDTH/HEIGHT/ASPECT=, =px=) from =@work.books/wavelet-hyperframes=;
  =onReady= builds the scene, =onTick(t)= drives it deterministically per frame;
  wavelet plays it back + exports the clip (ffmpeg is the muxing/encode tail,
  NOT the authoring surface). For raw still/clip edits — trim/concat/overlay —
  the =ffmpeg= toolkit is the right tool; HyperFrames is for *authored motion*.

  Skill index (read on demand):

  | Skill            | Use when                                               |
  |------------------+--------------------------------------------------------|
  | =scene=          | Author a HyperFrames scene (onReady/onTick, canvas)    |
  | =render-export=  | Render a scene to a clip + encode (wavelet → ffmpeg)   |
