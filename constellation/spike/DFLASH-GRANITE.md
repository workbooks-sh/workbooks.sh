# Building a Granite-4.1-8B block-diffusion drafter (DFlash recipe)

The novel piece (Constellation P2): replace the AR draft model with a BLOCK-DIFFUSION drafter so the
GPU lane drafts a whole block in ONE parallel forward. Source: DFlash (arXiv 2602.06036). The method
is general ("reuse frozen embed/head + train ~5 dense layers on self-distilled target data + KV-inject
sampled target features") — demonstrated on Llama-3.1 / Qwen3 / GPT-OSS. No Granite drafter exists and
the training code isn't public yet, so we IMPLEMENT from the paper.

## The drafter architecture
- **5 trainable plain-attention transformer layers** (NOT Mamba), at Granite's hidden size / head config.
- **Reuse Granite-4.1-8B's `embed_tokens` + `lm_head`, FROZEN** → exact vocab by construction; only the
  5 layers + a small KV-injection projection train (~few hundred M params).
- **KV injection (the conditioning):** take Granite hidden states from 5 layers uniformly spaced between
  layer 2 and (n_layers−3), project (target_dim→draft KV dim), write into the K/V of every draft layer,
  cache + reuse across drafting. (Granite is Mamba-hybrid → bias sampling toward its ATTENTION layers.)

## Block-diffusion mechanism (note: "diffusion" = parallel masked decode, NOT iterative denoising)
- **Block size N=16** (drop to 10/8 if acceptance poor). Masked positions in a block decoded in parallel
  in ONE forward (single step). Conditioned on context (KV-injected features) + last verified token.
- Inference loop: draft block → target verifies all N in one parallel pass → accept prefix → next block.

## Training
- **Loss:** position-weighted cross-entropy vs target-generated tokens; weight w_k=exp(−(k−1)/γ), **γ=7**.
  (self-distillation by teacher-forced tokens, not logit-KD)
- **Data:** ~800K prompts (Nemotron-PostTrain-V2 + CodeAlpaca, or OUR workbook/code domain mix) with
  **responses regenerated by Granite-4.1-8B itself** (target alignment is load-bearing). Cache target
  hidden features offline.
- **Hyperparams:** AdamW, lr 6e-4, cosine, warmup 0.04, grad-clip 1.0, 6 epochs, seq len 3072, 512 anchors/seq.
- **Compute:** trains on H100/H200; paper gives NO gpu-hours — estimate ~few hundred H100-hours (small
  drafter + cached features). Data-gen (Granite-8B regenerating 800K responses) is itself a big inference job.

## Inference (where it runs once trained)
- **MLX (Apple Silicon)** — DFlash has an MLX backend (tested Qwen3.5/Gemma-4) → runs on Mac. ✅
- **vLLM / SGLang (CUDA)** → the cloud/Vultr-GPU tier (SOTA speed here).

## Reported results (Qwen3-8B, lossless): Math 6.08× · Code 5.14× · Chat 2.75×. Up to 2.5× over EAGLE-3.

## Honest gaps / Granite risks
1. No gpu-hours/batch-size in paper (estimates only).
2. **Granite is Mamba-2/transformer HYBRID — outside DFlash's tested (dense-attention) envelope.** The
   feature-layer sampling for KV injection and N/γ are the params most likely to need empirical re-tuning.
   Nothing fundamentally blocks it (drafter stays plain transformer; embed/head/tokenizer compatible).
3. Needs a real GPU (not the M4) for data-gen + training. M4/MLX is for INFERENCE of the trained drafter.

## Build path
1. Implement drafter + training (PyTorch) from this spec — small proof-of-concept first (tiny data, few
   steps, validate the code + KV-injection wiring, even slowly).
2. Generate self-distill data (Granite-8B regenerates responses) — can use the Vultr CPU tier or a GPU.
3. Train on a rented/cloud GPU (H100-class), tune layer-sampling + N for the Mamba-hybrid.
4. Validate acceptance + speedup vs the AR 1B-draft baseline (1.19× on M4 today).
5. Serve: MLX on Mac, vLLM on CUDA. Slots into the Constellation GPU lane.

## ✅ POC VALIDATED (2026-06-18, on M4/MPS) — `dflash/poc3.py`
Built + ran the full core mechanic on granite-4.0-350m: frozen embed/head reuse + KV-injection
(cross-attend to Granite mid-layer context features) + block-masked parallel N-token prediction +
position-weighted CE. KEY BUG SOLVED: Granite I/O scaling (embedding_multiplier=12, logits_scaling=4,
final RMSNorm) — without it logits explode (loss in the 100s). With it: loss 5.9→2.3, block-acc
0%→38% on 600 toks toy data, 3-layer drafter. RECIPE IS SOUND FOR GRANITE (Mamba-hybrid fine; mid-layer
KV-injection worked). Remaining = SCALE not research: 8B base + 800K self-distill data + batching +
6 epochs + K=5/N=16 + a real GPU. PoC trains in ~50s on M4.
