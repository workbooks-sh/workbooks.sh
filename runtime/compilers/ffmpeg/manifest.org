#+SOURCE: ffmpeg 6.1.1 libav* + libx264 (GPL) — VIDEO (default): built-in png decoder + image2 demuxer + H.264 via in-guest libx264 (CRF 18/medium/high) + mp4 muxer + scale/format filters; a dependency-free mpeg4 encoder is the fallback (vcodec=mpeg4 / WB_VCODEC). AUDIO (optional 4th arg): built-in mp3/aac/wav/pcm decoders+demuxers + native AAC encoder + aresample/aformat filters, muxed as a 2nd stream into the same mp4. zlib 1.3.1. libx264 cross-compiled to wasm32-wasi (--disable-asm/-thread; config.sub+configure surgically patched for the wasi target). The AAC encoder is ffmpeg's own (no libfdk/lame). Single-threaded; ffmpeg CLI's pthread-bound fftools are bypassed via a hand-written libav* transcode driver (wb_encode.c). Cross-compiled with wasi-sdk-25 clang. Closes the wavelet mp4-encode bedrock gap INCLUDING H.264 + audio: H.264 video + AAC audio mux run in-guest under wasmtime at broker-matching quality, no host ffmpeg broker.
