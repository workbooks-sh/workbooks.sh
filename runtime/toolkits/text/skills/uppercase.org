* Uppercase a string

  Use when you need a string in upper case deterministically — a shout headline,
  a normalized key, an ALL-CAPS label — instead of casing it by hand in a prompt
  (which the model gets wrong on unicode + mixed scripts).

** Recipe

   The command reads stdin and writes the uppercased result to stdout:

   #+begin_src elixir
   {:ok, out} = Workbooks.CommandRegistry.run("upper", "made loud")
   # out == "MADE LOUD"
   #+end_src

   From inside a Workbook component (the agent path), through the Dock:

   #+begin_src text
   run-command("upper", "made loud")  -> "MADE LOUD"
   #+end_src

** Notes
   - Trims surrounding whitespace before casing.
   - Pure compute: no network, no filesystem — needs only the =commands= cap.
   - For title-case or other transforms, that's a different command, not this one.
