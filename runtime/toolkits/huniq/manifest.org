  Deduplicate lines from stdin while preserving first-seen order — unlike
  =sort -u=, which reorders. The wrapped CLI =huniq= is a third-party Rust crate
  we did NOT write; it compiles CLEAN to =wasm32-wasip1= (pure compute + stdio),
  so the declarative auto-wrap applies with ZERO glue:

  : #+EXEC: command          run as a registered WASM run-command
  : #+BUILD_SRC: crate:huniq  cargo install huniq --target wasm32-wasip1
  : #+BUILD_LANG: rust
  : #+ARG_MODE: argv          args reach the CLI as real wasmtime argv

  Build it with =work toolkit build huniq= → CommandRegistry registers =huniq= →
  any agent can =run-command("huniq", stdin)=.
