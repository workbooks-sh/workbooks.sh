Art-direction note. Every thumbnail in this vault is a reconstruction, not the live asset — a flat brand-palette block with the real headline set on top, so the board reads as creative strategy, not a screenshot dump. The winning pattern across the set is product-over-person framing: the boot, the shoe, the arena — the hero is the object, with the person in service of it. Talking-head / subject-forward framing is reserved only for true founder-story and dialogue creatives. Hard cuts, no fades; copy stays out of SKU-code territory.
