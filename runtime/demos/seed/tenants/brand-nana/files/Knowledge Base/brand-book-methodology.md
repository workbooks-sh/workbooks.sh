# Brand Nana — Brand Book Methodology

Every Brand Nana deliverable is **traceable**: no claim ships without a source
row behind it.

## The harvest
1. **Catalog** — full product feed (SKU, price, category, copy).
2. **Social** — profile-level signal across active channels.
3. **Ads** — live creative set, scored on hook + format.

## The render
- **Cover, logo system, color, type, voice, imagery** — derived, not invented.
- **Motion + AI-comms** section — how the brand behaves in 2026 surfaces.
- Each section footnotes the harvest rows it draws from.

## House rules
- Green/ink palette; red reserved for state (risk, landmines).
- Geist / Geist Mono. Tabular-nums on every figure.
- One source of truth per claim — drift is a defect.
